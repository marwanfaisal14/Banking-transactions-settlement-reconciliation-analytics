هذا مشروع Power BI بصيغة PBIP، وليس ملف PBIX جاهزًا.

1. نزّل BankingReconciliation-PowerBI.zip وفك الضغط بالكامل.
2. افتح BankingReconciliation.pbip باستخدام Power BI Desktop حديث على Windows.
3. اضغط Refresh. البيانات التجريبية مضمّنة؛ لا تحتاج ملفات CSV خارجية أو حساب بنك.
4. راجع الصفحات الثلاث والأرقام المذكورة في README.md.
5. اختر File ثم Save As ثم Power BI file (*.pbix).
6. احفظ BankingReconciliation.pbix وارفعه داخل مجلد powerbi على GitHub.

تغيير امتداد الملف من pbip إلى pbix لا ينشئ ملفًا صالحًا.
البيئة الحالية Linux؛ لم يتم فتح التقرير أو تنفيذ DAX أو حفظ PBIX داخل Power BI Desktop.
